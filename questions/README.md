# 質問集 (Questions Collection)

このディレクトリは、ClaudeやGitHub Copilotに質問したことやその回答を保存する質問集です。

## 目的

- 学習中に出てきた疑問点とその解決方法を記録
- 同じような問題に遭遇した時の参考資料として活用
- 学習の進捗と理解度の確認

## ファイル命名規則

質問の内容に応じて、分かりやすいファイル名を付けてください：

### React関連
- `react-component-basics.md` - コンポーネントの基本
- `react-state-management.md` - state管理について
- `react-hooks-usage.md` - Hooksの使い方
- `react-typescript-integration.md` - TypeScriptとの連携

### Rails API関連
- `rails-api-setup.md` - Rails API の設定
- `rails-controller-design.md` - コントローラーの設計
- `rails-database-configuration.md` - データベース設定
- `rails-cors-configuration.md` - CORS設定

### 統合・連携関連
- `frontend-backend-communication.md` - フロントエンド・バックエンド間通信
- `api-error-handling.md` - APIエラーハンドリング
- `docker-environment-issues.md` - Docker環境の問題

### その他
- `typescript-interface-design.md` - TypeScriptインターフェース設計
- `development-workflow.md` - 開発ワークフロー
- `debugging-techniques.md` - デバッグ手法

## ファイル形式

各質問ファイルは以下の形式で作成してください：

```markdown
# [トピック名]

## 質問 (Question)
[元の質問内容]

## 回答 (Answer)
[詳細な説明・回答]

## コード例 (Code Examples)
[提供されたコード例があれば]

## 関連資料 (Related Resources)
[チュートリアルの関連セクションや外部リソースへのリンク]

## 日時 (Date)
[質問した日付]
```

## 活用方法

1. **復習時の参考**: 過去に学習した内容を振り返る
2. **類似問題の解決**: 似たような問題に遭遇した際の参考
3. **学習進捗の確認**: どのような内容を学習してきたかの記録
4. **チーム共有**: 他の学習者との知識共有

## 注意事項

- 質問と回答は日本語で記録してください
- コード例には適切なコメントを含めてください
- チュートリアル教材の該当セクションへのリンクを含めてください
- 個人的な設定情報（パスワード、APIキーなど）は含めないでください

---

**💡 ヒント**: 質問する前に、まず `tutorial/` ディレクトリの関連セクションを確認してみましょう。多くの疑問は既存の教材で解決できるかもしれません。
